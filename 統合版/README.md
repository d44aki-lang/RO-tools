# RO.html について
　CT.htmlをリリースして以降、MVPcの販売金額等を記録するなら、コツコツ金策型もフォローしたいと思い立ってしまいました。
 管理は明らかに手間が増えますが、アイテムのドロップ数や販売金額等、お小遣い帳的に資産推移を見れるようにしたいと思い拡張しました。

 ## 初期設定について
 ### CT.htmlからのJSON出力
 - テーマ画面の最下部にJSON出力があります。押すとJSONファイルでDLできます。
 - ただし、形式が諸々異なるせいでキャラ名ぐらいしか引き継げないです。すみません。。

### じゃあ初期設定もろもろどうしたらいい？
 - まず、**金策分析をしたい人以外は旧ツールのまま**で問題ありません。

 - 手順１．「🎨設定・テーマ」をクリックし、「⚙️ 表示・動作設定」を確認します。
 　ここで各チェックボックスにチェックを入れて必要な機能をONにします。
　　テーマはお好きな配色、またはカスタムテーマで調整してください。

 - 手順２．「🚀ガイド」をクリックし、最下部の「🤖 AI一括登録用プロンプト」をコピーしてください。
　　生成AIを利用し、ROのキャラクター情報のサーバー名も見える範囲でスクリーンショットを撮影し、
  　このプロンプトと合わせてAIに渡すことで、サーバー名も追加された状態で抽出されます。
 
 -手順３．「👤キャラマスタ」をクリックし、JSON一括登録フォームに生成AIの回答をコピペして、一括登録を実行します。
　　資産額も管理したい方はおおよそでも良いのでキャラクターリストの基準所持金を記入し、右上の「💰 現在の所持金を基準点として保存」をクリックしてください。
  　現在の全キャラ所持ゼニーを総資産額として記録してくれます。
   　（今後はアイテムの売買履歴を保存することで記録時点以降の差額を補正して計算します。）
    N鯖のおサイフキャラは手順１でN鯖レートをONしているかどうかで入力金額を変えてください。

  -手順４．「🗓️MDマスタ」をクリックし、デフォルト適用ボタンを押すと、おおよそのMDとそこでドロップするアイテムが表示されます。
  　　ご自身の各MDの攻略度合いに応じてデフォルトで追加するアイテムの個数等を登録しておくことができます。
    　大量に用意したつもりなので、周回しないMDやアイテムは削除ボタンが右端にあるので削除しておくとスッキリします。
    　（MD進捗を記録する際に個数は変更可能ですが、★マークを付けたものでない限りアイテムの候補として出現しないため、レアは★マークをつけて０個にしておくとよいです。）
     さらに下にスクロールすると、宝箱などNPC売りすると固定の収入が見込めるアイテムのリストが記載されています。
     OC10で売ると思われるアイテムは自動的に記録されるようにしています。
  
  -手順５．「👑MVPc」をクリックし、手動行追加を押してください。
  　　CT.html時に記録している場合は複数行ドラッグしてコピーすると、空行を追加してCtrl+Vで貼り付けをすれば一括で貼付けできます。
    　また、記録途中の場合は、任意数設定を押していただくと現在の累計討伐数を任意変更できます。
     　変更点として、MVP履歴は最新のものほど上に表示されるようにしています。（旧は新しいものほど下にソートしていました。）

  以上で初期設定は終わりです。

 ## 通常運用について
 ### MD進捗画面
   - 左上にサーバー単位での絞り込みボタンを追加しました。
   - キャラ毎に左クリックでチェックをつけると、右側にアイテムのフィールドが出現します。保存ボタンを押すとアイテム在庫として記録されます。

 ### 取引・在庫画面
　- MD進捗記録時にドロップを記録すると、在庫が貯まります。
  - 販売時もしくは装備更新時等の際に、取引記録入力画面で取引の記録を保存できます。
  - オススメはおおよその金額程度にしておかないと記録疲れしちゃうと思います。
  - また、現時点で既に倉庫にある場合は、右側の在庫・単価一覧フィードにて、初期在庫の追加もできます。

### ダッシュボード
 - 総資産・所持金や、収益トレンドやMD別の金銭効率を表示できます。
