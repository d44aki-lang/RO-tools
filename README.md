# RoLog ✨ - Ragnarok Online 統合管理ダッシュボード

RoLogは、ラグナロクオンライン（RO）のメモリアルダンジョン（MD）進捗、資産推移、MVPカード獲得履歴を一台で管理できる高機能・軽量ダッシュボードツールです。
HTMLファイル1つで動作し、データはすべてブラウザ（IndexedDB）に安全に保存されます。

---

## 🌟 主な機能

### 1. MD進捗管理
- **直感的な操作**: クリックで完了（✔）、右クリックで対象外（－）を切り替え。
- **自動CT計算**: 翌日5:00、3日後5:00、火曜12:00などのリセット時間を自動計算し、時間を過ぎると未完了に戻ります。
- **柔軟な表示**: サーバー別のタブ切り替え、縦横表示（行列入れ替え）に対応。

### 2. 高度な資産管理（金策モード）
- **ドロップ即時精算**: MD完了時にドロップ品を入力すると、NPC価格マスタに基づき自動的に売却（現金化）処理されます。
- **在庫管理**: 売却せず保持するアイテムは「在庫」として蓄積され、推定市場価格に基づき資産価値が計算されます。
- **収支統計**: 週次の収益トレンド、資産推移、MD別の効率分析（平均収益）をグラフで可視化します。

### 3. MVPカウンター & 統計
- **累計討伐数**: MDクリアに連動してMVP討伐数を自動カウント。
- **カード獲得記録**: カード獲得時にカウンターをリセットし、獲得日・累計討伐数・売却額を履歴として保存。
- **年度別統計**: 年ごとの獲得枚数や累計利益を一覧表示。

### 4. カスタマイズ性
- **60種類のテーマ**: 深夜に優しいダークモードから、サイバーパンク、レトロ、ハイコントラストまで。
- **カスタムテーマ**: 全てのパーツの色を自分好みに変更可能。

---

## 🚀 はじめての設定方法

まずは以下の手順で自分用の環境を整えましょう。

### 手順1：MDマスタの初期化
「**MDマスタ**」タブを開き、「**デフォルト適用**」ボタンを押してください。主要なMDとドロップ品、MVP数が一括登録されます。

### 手順2：キャラクターの登録
「**キャラマスタ**」タブでキャラクターを登録します。
- **AIプロンプトの活用**: 公式ツールの「キャラクター情報」のスクリーンショットをAI（Gemini等）に渡し、ガイド下部のプロンプトを貼り付けることで、一括登録用のJSONを生成できます。

### 手順3：金策モードの有効化
詳細な収支を管理したい場合は、「**設定・テーマ**」タブで「**金策分析モードを有効化**」にチェックを入れてください。

### 手順4：資産の基準設定（オプション）
現在の所持金を反映させたい場合は、各キャラの「基準所持金」を入力し、「**現在の所持金を基準点として保存**」を押してください。

## ⚔️ 日々の使い方

1. **MDを回す**: 周回が終わったら「**MD進捗**」で対象のセルをクリックします。
2. **ドロップを入れる**: チェック時にポップアップが出るので、拾った個数を入力します（NPC価格マスタにあるものは自動売却、それ以外は在庫に入ります）。
3. **露店で売る**: 溜まった在庫を売却した際は「**取引・在庫**」タブで記録します。「100k」「1.5M」といった単位入力が可能です。
4. **ダッシュボードを確認**: 「**ダッシュボード**」で今週の周回数や収益状況を確認してモチベーションを維持しましょう。

---

## ⚠️ 注意事項・バックアップ

- **データの保存先**: データはあなたのブラウザ内に保存されています。ブラウザのキャッシュを完全に消去すると、データも削除される可能性があります。
- **バックアップの推奨**: 「**設定・テーマ**」タブから定期的に「**バックアップ出力**」を行い、JSONファイルをPC内に保存しておくことを強くお勧めします。
- **推奨ブラウザ**: Google Chrome, Microsoft Edge などの最新版ブラウザ。
